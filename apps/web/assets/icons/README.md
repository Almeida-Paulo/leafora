# Interface assets

- `interface.svg`: Lucide symbols, distributed under the ISC license in `LICENSE.txt`.
  Project-category symbols use the official Lucide `trees` (REDD+), `sprout`
  (ARR), and `wheat` (ALM) paths, retrieved on 2026-10-21. Their 24 x 24
  viewBox is preserved and the stroke is set to 1.7 to match this sprite.
  Sources: https://github.com/lucide-icons/lucide/blob/main/icons/trees.svg,
  https://github.com/lucide-icons/lucide/blob/main/icons/sprout.svg,
  https://github.com/lucide-icons/lucide/blob/main/icons/wheat.svg.
- `freighter.svg`: the Freighter symbol from the official `stellar/freighter`
  repository, `extension/src/popup/assets/logo-freighter.svg`. The two key paths
  are preserved; the wordmark and background were removed, the viewBox cropped,
  and the fill changed to Leafora's monochrome ink for the wallet chooser.
  Source: https://github.com/stellar/freighter/blob/master/extension/src/popup/assets/logo-freighter.svg
  Apache 2.0 license: `../../vendor/stellar/freighter-LICENSE.txt`.

Wallet marks identify the available provider; they do not indicate endorsement.
